## Files Created

### Source skeleton and styles

| File | Purpose |
|---|---|
| `src/html/configurator.html` | HTML skeleton: wizard markup (mode selector, engagement/scope/review/download steps) with stable `data-testid` attributes; `<!-- BUILD:CSS -->` and `<!-- BUILD:JS -->` placeholders for build-time inlining |
| `src/css/styles.css` | All styles for the configurator, inlined at build |

### JavaScript modules (concatenated in dependency order at build)

| File | Purpose |
|---|---|
| `src/js/constants.js` | `TEMPLATE_VERSION` — the single version literal in the codebase; read by both build outputs (BR-C-11) |
| `src/js/app.js` | Entry point: `generateAndDownload()` (final revalidation → generator fan-out → version stamp → full package) and `downloadFile()` (Blob download); single-quote containment helper applied at every shell interpolation point (BR-C-10) |
| `src/js/shared/ui.js` | `selectMode()`, wizard step navigation and gating (BR-C-08), field-error rendering |
| `src/js/i18n/engine.js` | `t(key, params)` lookup engine with `en` fallback (BR-C-22) |
| `src/js/i18n/{en,id,ja,ko,th,vi,zh}.js` | 7 locale dictionaries; identical key sets, test-enforced (BR-C-21) |
| `src/js/deploy/deploy-flow.js` | Deploy-mode wizard flow: collects deployment target + scope, drives generation |
| `src/js/delete/delete-flow.js` | Delete-mode flow (script content rules owned by unit-5) |
| `src/js/upgrade/`, `src/js/editor/` | Lifecycle flow modules (upgrade owned by unit-5; editor scaffolded) |

Validation logic (BR-C-01…08: MPE ID format/length, date ordering + plausibility
warning, 12-digit account IDs, ALL/EXPLICIT mutual exclusivity, VPC format,
forced non-VPC switch) is implemented in the shared/flow modules and runs at
blur, step-transition, and pre-generation.

### Build tooling

| File | Purpose |
|---|---|
| `scripts/build.js` | Assembles `configurator.html`: inlines CSS, concatenates JS in dependency order (constants → i18n → services → shared → flows → app), embeds `src/templates/lambda-handler.py` indented for YAML; deterministic output (BR-C-32) |
| `scripts/verify-build.js` | Post-build sanity gate: no unresolved `BUILD:` placeholders, entry functions present, zero external URL / fetch / analytics references — the auditable no-network check (US-18) |
| `package.json` | `build`, `build:yaml`, `test`, `verify` scripts |

| Area | What it locks in |
